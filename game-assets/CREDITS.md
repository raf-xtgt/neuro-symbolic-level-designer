## Redistribution Rules for This Repository

* `death_city.zip` is listed in the repository `.gitignore`. It stays on the developer machine only. Do not commit it or any of its unprocessed files. Commit only the processed, in-game spritesheets.
* Any file derived from a CC-BY-SA asset (for example, a re-sliced or recolored grassland or desert tileset) must stay under CC-BY-SA 3.0.
* Keep this file up to date when an asset is added or removed.
